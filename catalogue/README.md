# Exercise catalogue

Each `exercises/<id>.json` entry describes a movement in English: name, equipment, target muscles, instructions, and optional muscle-map geometry. IDs are stable references used by routines and logs; never reuse an ID. The application currently ships an English-only UI with en-US dates.

Text marked `textSource: "exercisedb"` retains the MIT attribution reproduced in [NOTICE.md](../NOTICE.md). Other catalogue text is covered by the project's AGPL license. Contributions should use original descriptions and preserve source notices.

`media/still/<id>.webp` and `media/clip/<id>.mp4` contain licensed exercise illustrations at 180 px. **These are not AGPL assets.** They are included for use within openGym only, under the terms reproduced in [media/NOTICE.md](media/NOTICE.md). Do not extract, hotlink, reuse in an independent product, or feed this media to an AI system. Other uses require a separate license from Gym visual.
