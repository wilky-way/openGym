# Synthetic screenshots

These images were captured with `agent-browser` from the built application using the invented fixture generated by `bun scripts/screenshot-fixture.ts`.

- `planner.png`: month schedule with synthetic completed and projected sessions.
- `history.png`: six invented workout logs with correctly calculated set volume.
- `programme.png`: settled read-only session preview with sets, repetitions, effort, and rest.

The capture used a fresh guest browser profile, a loopback-only preview port, and a disposable server data directory. No real account, exported state, private library, or credential was used. The temporary server was stopped by its recorded PID after capture.

To reproduce, build the app, start the compiled server on a free loopback port with a temporary `--data-dir` and `--static-dir ./packages/web/dist`, and open it in a fresh agent-browser session. Load the fixture JSON into `gym_state_v1`, set `gym_guest=1`, and reload. Capture the Plan calendar, History, and a session's Preview after transitions settle. Never use a personal browser profile or account for repository screenshots.
